# Desafio: Acordeão

## Objetivo

Construir um componente acrodeão que permita abrir e fechar seções ao clicar nos títulos. Apenas uma seção deve estar aberta por vez.

## Estrutura do Projeto

- `acordeao.html` - arquivo HTML com a estrutura do acordeão.
- `acordeao.css` - estilos para esconder/mostrar conteúdo e animações.
- `acordeao.js` - script para controlar a abertura e fechamento das seções.

## Passo a Passo

1. Criar a estrutura HTML com botões e conteúdos escondido.
2. Estilizar com CSS para esconder o conteúdo e adicionar transições.
3. Usar JavaScript para adicionar evento ao clique e abrir/fechar seções.
4. Garantir que somente uma seção esteja aberta por vez.

## Conceitos Usados

- HTML: `<button>`, `<div>`, estrutura semântica.
- CSS: `max-height`, `overflow`, `transition`, classes dinâmicas.
- JavaScript: manipulação do DOM, `classList.toggle()`, eventos de clique.
