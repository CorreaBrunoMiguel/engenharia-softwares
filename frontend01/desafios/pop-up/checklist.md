# ✅ Checklist: Componente Pop-up

## Estrutura HTML

- [ ] Criar botão de disparo
- [ ] Criar container do modal com:
  - [ ] `role="dialog"`
  - [ ] `aria-modal="true"`
  - [ ] `aria-labelledby`
  - [ ] `aria-describedby`

## Estilização (CSS)

- [ ] Overlay com fundo escuro
- [ ] Modal centralizado e com animação suave
- [ ] Responsivo (mobile e desktop)
- [ ] Prevenir rolagem do body
- [ ] Transição para entrada e saída

## JavaScript

- [ ] Abrir modal ao clicar no botão
- [ ] Fechar com:
  - [ ] Botão fechar
  - [ ] Tecla ESC
  - [ ] Clique fora do modal
- [ ] Mover foco para o modal ao abrir
- [ ] Retornar foco para o botão ao fechar
- [ ] Permitir múltiplos modais (conteúdo dinâmico)

## Acessibilidade

- [ ] Teste com leitor de tela
- [ ] Atributos ARIA aplicados corretamente
- [ ] Teclado navega entre os elementos internos

## Testes

- [ ] Testar em diferentes navegadores
- [ ] Testar no mobile
- [ ] Validar com teclado (sem mouse)
