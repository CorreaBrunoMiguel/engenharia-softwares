### 🧠 Quiz – CSS Grid (versão embaralhada)

## NOTA: 100%

**1. Qual propriedade define a quantidade e tamanho das colunas em um grid container?**

- [ ] `grid-auto-flow`
- [x] `grid-template-columns`
- [ ] `grid-template-areas`
- [ ] `grid-column-start`

---

**2. Qual a diferença entre `auto-fit` e `auto-fill` ao usar `repeat()`?**

- [ ] `auto-fit` preenche o grid com colunas vazias; `auto-fill` compacta
- [ ] Nenhuma diferença
- [x] `auto-fill` preenche o grid com colunas mesmo vazias; `auto-fit` compacta para ocupar espaço disponível
- [ ] Ambos criam colunas vazias se necessário

---

**3. O que o valor `1fr` representa?**

- [ ] A largura do conteúdo mínimo
- [x] 1 parte proporcional do espaço restante
- [ ] 1 linha de altura automática
- [ ] 1 pixel fixo

---

**4. O que faz a propriedade `grid-auto-rows: minmax(100px, auto);`?**

- [x] Define linhas com altura mínima de 100px, podendo crescer conforme o conteúdo
- [ ] Define a altura máxima da linha como 100px
- [ ] Remove qualquer altura das linhas
- [ ] Garante que cada linha tenha exatamente 100px

---

**5. Como centralizar um item dentro de uma célula Grid?**

- [ ] `display: flex; align-items: center;`
- [ ] `align-content: center; justify-items: center;`
- [ ] `margin: auto; padding: auto;`
- [x] `align-self: center; justify-self: center;`

---

**6. Dado um item com `grid-column: 2 / 4`, o que isso significa?**

- [x] O item ocupa as colunas 2 e 3
- [ ] O item ocupa 4 colunas
- [ ] O item começa na linha 2 e vai até a 3
- [ ] O item começa na coluna 4

---

**7. É possível usar Grid e Flexbox juntos no mesmo layout?**

- [ ] Sim, mas somente se forem aplicados em elementos irmãos
- [ ] Apenas em navegadores com suporte a CSS Modules
- [x] Sim, é comum usar Grid para layout principal e Flexbox para conteúdo interno
- [ ] Não, são sistemas incompatíveis
