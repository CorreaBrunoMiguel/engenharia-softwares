# Criar um Acordeão Simples com HTML, CSS e JavaScript

## Objetivo

Construir um componente acordeão com 3 seções, onde só uma seção pode estar aberta por vez. ao clicar no título da seção, o conteúdo aparece; ao clicar em outra seção, a anterir fecha.

## Requisitos

- Estrutura HTML simples com botões/títulos e conteúdo associado.
- CSS para esconder/exibir o conteúdo com transições suaves.
- JavaScript para controlar a abertura e fechamento das seções, garantindo que apenas uma esteja aberta.
- Conteúdo detro de cada seção pode ser texto simples ou Lorem Ipsum.
